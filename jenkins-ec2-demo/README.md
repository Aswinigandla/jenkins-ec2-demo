# Jenkins EC2 Demo

A simple static website for practicing Git, GitHub, Jenkins, and AWS EC2.

## Open in VS Code
1. Extract `jenkins-ec2-demo.zip`.
2. Open the extracted `jenkins-ec2-demo` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Upload to GitHub
Open a terminal in this folder and run:

```bash
git init
git add .
git commit -m "Add demo web application"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/jenkins-ec2-demo.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. Create the GitHub repository first.
